
# Ubuntu Command & Service Helper

A lightweight reference utility designed for developers and system administrators working within Linux and Ubuntu environments.

## 🚀 Features
- **Categorized Reference:** Quick access to essential `systemctl`, `journalctl`, `ufw`, and `dpkg` commands.
- **Interactive Search:** Instant filtering across commands, tags, and usage descriptions.
- **Category Badges:** Visual distinction between networking, security, logs, and package management tools.

## 🛠️ Tech Stack
- **Framework:** React
- **Language:** TypeScript
- **Styling:** CSS3
